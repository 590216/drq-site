# DRQ Facebook editorial rule

Confirmed by Ian on 4 September 2026.

- Include **#DRQUpdate** in official Darwin River Quarries Page posts intended for the website.
- Use Danny's personal Facebook profile for personal comments and unrelated activity.
- Publish official business updates directly on the DRQ Page, using accurate copy and appropriate images.
- When drafting official DRQ posts intended for the website, include #DRQUpdate.

## Implementation status

The current feed implementation is restricted to approved post `109709817601324_1719423730192457`. Hashtag-based automatic selection has been agreed as the intended rule but has NOT been implemented or verified. Adding the hashtag alone does not yet cause a new post to appear on the website.
